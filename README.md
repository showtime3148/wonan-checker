# 정기시험 원안지 점검기 (개인용)

예당고등학교 교감 개인 점검용 웹앱입니다. 비밀번호를 넣어야 열립니다.

- 원안지 파일(HWPX·PDF·스캔 PDF)은 **브라우저 안에서만** 처리되고 서버로 전송되지 않습니다.
- `vercel.json`의 보안 헤더(Content-Security-Policy)가 이 페이지의 모든 외부 통신을 막습니다.
- 앱 본문은 암호화되어 있어 저장소에서도 내용(코드·평가계획 데이터)이 보이지 않습니다.
- 검색엔진 노출을 막도록 `robots.txt`와 `X-Robots-Tag`를 넣었습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱(비밀번호로 암호화된 단일 파일, 약 9MB) |
| `vercel.json` | 보안 헤더 설정 |
| `robots.txt` | 검색 차단 |

## 업데이트할 때

새로 받은 `index.html`로 바꿔 올리면(커밋) Vercel이 자동으로 다시 배포합니다.
